토큰전쟁 자료실

AI에게 그림 실력을 달아 주는 법

클로드는 원래 그림을 못 그려요. 허깅페이스의 무료 그림 모델을 연결해 두면 "그려 줘" 한마디로 그림이 나와요. 눈(watch 스킬)까지 달면 영상을 보고 그 내용을 그림으로 정리해 줘요.

준비물

  • 클로드 유료 요금제 (Pro 이상)
  • 컴퓨터 (윈도우 또는 맥)
  • 허깅페이스 가입·키는 없어도 돼요
1클로드 코드 열기

클로드 앱 → 왼쪽 위 'Code' → 폴더 하나 고르기

앱이 없으면 claude.ai/download 에서 컴퓨터용 앱을 받아 로그인해요. 그린 그림은 고른 폴더에 저장돼요.

2그림 모델 연결

아래 문장을 그대로 붙여 넣기

허깅페이스의 무료 그림 모델 스페이스 black-forest-labs/FLUX.1-schnell 을 파이썬 gradio_client 로 연결해 줘. 앞으로 내가 "그려 줘"라고 하면 이걸로 그림을 그려서 이 폴더에 저장해 줘.

필요한 프로그램을 설치해도 되는지 물어보면 '응'이라고 하면 돼요.

3그려 달라고 하기

원하는 그림을 말로 설명

코르크판 수사 보드를 그려 줘. 사람 실루엣 사진 몇 장과 빨간 실, 한가운데 큰 빈 액자. 로우폴리 3D 느낌, 글자는 넣지 마.

그림 속 글자는 깨져 나오기 쉬워서 "글자는 넣지 마"를 붙이면 깔끔해요.

4눈과 같이 쓰기

영상을 보고 그림으로 정리

이 영상들 보고 내용을 정리한 수사 보드 그림을 그려 줘. 글자는 넣지 마: (영상 링크들)
