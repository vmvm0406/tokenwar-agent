RSI Recursive Self-Improvement
재귀적 자기 개선

AI가 스스로를 고쳐 더 나은 다음 버전을 만들고, 그 버전이 또 다음 버전을 만드는 것. 한 번 돌 때마다 고치는 실력도 늘어서 점점 빨라질 수 있다는 생각입니다.

예: "제가 저를 고치고, 고친 제가 또 저를 고치고…"

모델 붕괴 Model Collapse

AI가 사람이 쓴 글 대신 AI가 만든 글로만 계속 배우면, 드문 내용부터 사라지며 점점 엉뚱해지는 현상. RSI와 반대로 "AI끼리만 배우면 망가진다"는 쪽의 근거입니다.
