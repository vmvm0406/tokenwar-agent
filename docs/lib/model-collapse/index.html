모델 붕괴

Model Collapse. AI가 사람이 쓴 글 대신 AI가 만든 글로만 계속 배우면, 점점 엉뚱해지는 현상이에요.

1어떻게 망가질까

드문 내용부터 사라져요

AI가 만든 글은 흔한 내용 위주라서, 그걸로 다시 배우면 드물고 특이한 내용이 점점 빠져요. 몇 세대가 지나면 처음과 전혀 다른 말을 하기도 해요.

2실험 예

중세 건축 글이 산토끼 목록으로

연구진이 AI 글로 AI를 아홉 세대 거듭 학습시켰더니, 중세 건축에 대한 글이 엉뚱한 산토끼 종류 목록으로 바뀌었어요.

3그래서

사람이 쓴 글이 계속 필요해요

AI가 만든 글을 학습에 쓰려면 잘 골라내야 한다는 게 연구진의 결론이에요. RSI와 반대쪽 근거로 자주 나와요.
