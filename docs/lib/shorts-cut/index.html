열 시간짜리 방송도, 한 시간짜리 강의도 클로드에게 맡기면 재밌는 부분만 골라 세로 쇼츠 파일로 잘라 줘요. 편집 프로그램 몰라도 복사·붙여넣기만 하면 돼요.

준비물

  • 클로드 유료 요금제 (Pro 이상)
  • 컴퓨터 (윈도우 또는 맥)
  • 올릴 거라면: 내가 찍은 영상이거나, 클립 만들기를 허락한 방송
1클로드 앱 설치

claude.ai/download 에서 받아 설치하고 로그인

휴대폰 말고 컴퓨터용 앱이에요.

2'Code' 열기

앱 왼쪽 위 'Code'를 누르고 폴더 하나 고르기

바탕화면에 새 폴더(예: 쇼츠)를 만들어 고르면, 잘린 영상이 그 폴더에 생겨요.

3눈 달기

아래 문장을 그대로 붙여 넣기

클로드가 영상을 볼 수 있게 해 주는 스킬이에요. 설치가 끝나면 '새 대화'를 열어 주세요. 이미 눈을 달았다면 넘어가도 돼요.

4잘라 달라고 하기

링크(또는 영상 파일)와 함께

처음 한 번은 클로드가 몇 가지를 물어봐요.

  • 보는 방법은 local(내 컴퓨터에서 보기), 받아쓰기는 none을 고르면 키 없이 바로 돼요. 유튜브 영상은 자막으로 말까지 알아들어요.
