클로드에게 손 달아 주는 법

'클로드 인 크롬'(Claude in Chrome)을 깔면 클로드가 크롬 브라우저 옆 창에서 지금 보는 페이지를 읽고, 탭을 오가며 버튼을 누르고, 내용을 입력해 줘요.

준비물

  • 클로드 유료 요금제 (Pro 이상)
  • 컴퓨터의 구글 크롬 (다른 브라우저·휴대폰은 안 돼요)
1확장 프로그램 설치

크롬 웹 스토어에서 'Claude' 검색 → 'Chrome에 추가'

앤트로픽(Anthropic)이 만든 공식 확장 프로그램인지 꼭 확인하세요.

2로그인·고정

클로드 계정으로 로그인하고, 툴바에 고정

오른쪽 위 퍼즐 모양 아이콘 → 'Claude' 옆 압정을 누르면 늘 보여요. 처음에 묻는 권한을 허용해 주세요.

3일 맡기기

툴바의 클로드 아이콘 → 옆 창에서 부탁하기

지금 보고 있는 쇼핑몰에서 김밥 메뉴 가격을 표로 정리해 줘.

클로드가 작업하다 확인이 필요한 일이 생기면 멈추고 물어봐요.
