토큰전쟁 자료실

AI에게 눈을 달아 주는 법

클로드는 원래 영상을 못 봐요. '눈'(watch 스킬)을 한 번 달아 두면, 영상 링크만 줘도 장면을 하나하나 보고 답해 줘요. 코딩 몰라도 복사·붙여넣기만 하면 돼요.

준비물

  • 클로드 유료 요금제 (Pro 이상)
  • 컴퓨터 (윈도우 또는 맥)
1클로드 앱 설치

claude.ai/download 에서 받아 설치하고 로그인

휴대폰 말고 컴퓨터용 앱이에요.

2'Code' 열기

앱 왼쪽 위 'Code'를 누르고 폴더 하나 고르기

바탕화면에 새 폴더를 하나 만들어 골라도 돼요. 여기가 클로드 코드예요.

3눈 달기

아래 문장을 그대로 붙여 넣기

bradautomates/claude-video 의 watch 플러그인을 설치해 줘.

설치가 끝나면 '새 대화'를 하나 열어 주세요. 그래야 눈이 달려요.

4영상 보여 주기

링크와 궁금한 것을 함께

이 영상 보고 무슨 일이 있는지 장면별로 알려 줘: (영상 링크)

처음 한 번은 클로드가 몇 가지를 물어봐요.

  • 바로 쓰려면 local(내 컴퓨터에서 보기) → 받아쓰기는 none 고르기. 키 없이 바로 돼요.
  • 말소리까지 알아듣게 하려면 gemini를 고르고, 클로드가 알려 주는 대로 무료 키를 받아 붙여 넣기 (aistudio.google.com/apikey).

필요한 프로그램이 없으면 클로드가 설치해도 되는지 물어봐요. '응'이라고 하면 돼요.

5이렇게도 써 보세요
  • 유튜브 강의 링크 → "핵심만 5줄로 정리해 줘"
  • 내 릴스 링크 → "첫 3초가 지루한지 봐 줘"
  • 뉴스 영상 링크 → "사실과 의견을 나눠 줘"
✓결과 예시

인스타 릴스 링크 하나로
