ChatGPT가 이제
내 카드로 결제합니다

옆으로 넘겨 보기 · 8장
캡션
ChatGPT가 이제 내 카드로 물건값을 대신 냅니다. 결제 순서와 안전장치를 한 번에 정리했어요.

OpenAI가 11월 13일 'ChatGPT Wallet'을 발표했어요. AI 비서(dot)가 물건을 고르면, 사람이 물건·총액·카드를 확인하고 Face ID나 지문으로 승인해야 결제돼요.
AI도 가게도 진짜 카드 번호는 보지 못하고, 카드사가 결제마다 대신 쓸 번호를 만들어 줘요. 비자·마스터카드·아메리칸 익스프레스와 함께 만들었어요.
지금은 미국의 18세 이상 ChatGPT Pro 구독자만 쓸 수 있고, 다른 나라 출시 시점은 나오지 않았어요.

말 한 줄에 클로드가
PPT 8장을 만듭니다

캡션
클로드 코드에 말 한 줄 넣고 발표용 PPT 8장을 파일로 받아 보세요.

11월 16일에 직접 넣어 본 문장은 이거예요.

"팀원들에게 '금요일 점심 도시락 모임'을 제안하는 발표 PPT를 8장으로 만들어 줘. 새 프로그램은 설치하지 말고 이 컴퓨터의 파워포인트로 만들어서 이 폴더에 lunch.pptx로 저장해."

6분쯤 뒤 폴더에 lunch.pptx가 생겼고, 표지와 진행 시간표, 기대 효과, 주차별 도시락 테마, 다음 일정까지 8장이 채워져 있었어요. 다 만든 뒤에는 장을 그림으로 뽑아 스스로 검사도 했어요.

다만 한글이 단어 중간에서 줄이 바뀐 곳이 있었어요('피 / 곤해요'). 클로드도 고치려다 못 고쳤다고 알려 왔으니, 발표 전에 장마다 훑어보고 직접 고쳐 주세요. 넣어 준 날짜도 예시예요.

사진을 그림으로 바꾸는 앱,
클로드가 직접 만들어 줍니다

옆으로 넘겨 보기 · 8장
캡션
클로드한테 그림을 한 장씩 그려 달라고 하지 말고, 사진을 그림으로 바꿔 주는 앱을 통째로 만들어 달라고 해 보세요.

클로드에 아래 프롬프트를 넣었더니 HTML 파일 하나짜리 사진 변환기가 나왔어요. 받은 코드를 .html 파일로 저장해 브라우저로 열고 사진을 끌어다 놓으면 연필 스케치, 모자이크, 팝아트로 바뀌고 PNG로 저장돼요. 내 컴퓨터 안에서 도니까 몇 장을 바꿔도 횟수 걱정이 없어요.

"사진을 올리면 그림으로 바꿔 주는 웹 앱을 HTML 파일 하나로 만들어 줘. 스타일은 팝아트 망점, 연필 스케치, 모자이크 세 가지. 사진은 서버로 보내지 말고 브라우저 안에서만 처리하고, 결과를 PNG로 저장하는 버튼도 넣어 줘."

11월 16일에 직접 돌려 보니 연필 스케치는 강아지 털 결까지 살았고, 앱이 외부로 보내는 요청도 없었어요. 다만 팝아트는 배경 색이 얼룩덜룩하게 뭉쳤어요. 같은 프롬프트라도 매번 조금씩 다른 코드가 나올 수 있어요.
