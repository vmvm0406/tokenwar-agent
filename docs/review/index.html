클로드에게 한 문단만 말했더니 지하철 짐 피하기 게임이 나왔어요.

코딩은 하지 않았어요. 아래 문장을 클로드에 넣으면 HTML 파일 하나짜리 게임을 만들어 줘요. 파일로 저장해 크롬으로 열면 바로 플레이할 수 있어요.

"지하철 선반에서 떨어지는 짐을 피하는 게임을 HTML 파일 하나로 만들어 줘. 나는 화면 아래 승객이고 방향키로 좌우로 움직여(휴대폰은 화면 왼쪽·오른쪽 터치). 가방, 커피, 우산이 떨어지고 부딪히면 끝. 버틴 시간이 점수고, 10초마다 2호선 다음 역 이름이 뜨면서 점점 빨라지게 해 줘."

첫 결과는 짐이 작고, '동대문역사문화공원'처럼 긴 역 이름이 안내판 밖으로 삐져나왔어요. 한 번 더 말해서 고친 게 영상 속 게임이에요. 저희는 같은 문장을 클로드 코드(Claude Opus 5.5)에 넣어 만들었어요.
