PPT를 만듭니다

클로드 코드에 문장 하나를 넣으면 컴퓨터에 설치된 파워포인트로 발표 자료를 만들어 폴더에 저장합니다. 아래는 테스트에 사용한 문장과 결과입니다. 따옴표 안의 주제와 장 수를 바꿔 사용하십시오.

01사전 준비

파워포인트가 설치된 컴퓨터를 준비합니다

이 문장은 컴퓨터에 설치된 파워포인트로 파일을 만듭니다. 새 프로그램은 설치하지 않습니다. 윈도우 11과 파워포인트 16.0에서 테스트했습니다.

02사전 준비

터미널부터 엽니다

터미널은 마우스 대신 글자로 컴퓨터에 일을 시키는 창입니다. 커서만 깜빡이는 빈 창이 뜨면 맞게 연 것입니다. 이 페이지의 명령은 복사 버튼으로 복사해 그 창에 붙여 넣고 Enter를 누르면 됩니다.

윈도우

시작 메뉴에서 PowerShell을 검색해 열거나, Win + X를 누르고 Windows PowerShell(또는 터미널)을 고릅니다. 줄 앞에 PS가 붙어 있으면 PowerShell입니다. 붙여 넣기는 Ctrl + V 또는 마우스 오른쪽 클릭입니다.

출처: Claude Code 공식 문서: 처음 쓰는 사람을 위한 터미널 안내

맥

Cmd + Space로 Spotlight 검색을 열고 '터미널'(Terminal)을 입력한 뒤 Enter를 누릅니다. 붙여 넣기는 Cmd + V입니다.

출처: Claude Code 공식 문서: 터미널 안내

리눅스

대부분의 배포판에서 Ctrl + Alt + T를 누르거나, 앱 메뉴에서 '터미널'을 찾습니다. 붙여 넣기는 Ctrl + Shift + V입니다.

출처: Claude Code 공식 문서: 터미널 안내

03사전 준비

클로드 코드를 설치합니다

공식 문서에 있는 설치 명령 그대로입니다. 받는 동안 진행 표시가 없으니 창을 닫지 말고 기다립니다. 끝나면 터미널을 새로 열고 확인 명령을 넣어 버전 숫자가 나오면 성공입니다. 처음 claude를 실행하면 브라우저가 열려 로그인합니다. 무료 요금제로는 쓸 수 없고 Pro 이상 요금제가 필요합니다.

윈도우 (PowerShell)

irm https://claude.ai/install.ps1 | iex

출처: Claude Code 공식 문서: 설치

윈도우 (CMD, 줄 앞에 PS가 없는 창)

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

출처: Claude Code 공식 문서: 설치

맥 · 리눅스

curl -fsSL https://claude.ai/install.sh | bash

출처: Claude Code 공식 문서: 설치

설치 확인 (공통)

2.1.281 (Claude Code)처럼 버전이 표시되면 정상입니다. claude를 찾을 수 없다고 나오면 터미널을 닫았다 다시 열어 확인합니다.

claude --version

04클로드 켜기

빈 폴더를 만들고 그 안에서 클로드를 켭니다

클로드는 켠 폴더 안에 파일을 만듭니다. PPT 파일이 다른 파일과 섞이지 않도록 빈 폴더를 하나 만들어 그 안에서 켭니다. 터미널을 새로 열고 아래 세 줄을 한 줄씩 넣고 Enter를 누릅니다. 첫 줄은 ppt-test이라는 빈 폴더를 만들고, 둘째 줄(cd)은 그 폴더로 들어가고, 셋째 줄이 클로드를 켭니다. 켜진 창이 다음 단계의 프롬프트를 붙여 넣을 곳입니다. 파일을 만들거나 바꾸기 전에 허락을 물으면 내용을 확인한 뒤 Enter로 승인합니다.

윈도우 (PowerShell)

터미널은 C:\Users\내 이름 폴더에서 시작하므로, 새 폴더는 C:\Users\내 이름\ppt-test에 생깁니다.

mkdir ppt-test
cd ppt-test
claude

출처: Claude Code 공식 문서: 작업할 폴더에서 claude 실행

맥 · 리눅스

터미널은 내 홈 폴더(맥은 /Users/내 이름, 리눅스는 /home/내 이름)에서 시작하므로, 새 폴더는 그 안에 ppt-test으로 생깁니다.

mkdir ppt-test
cd ppt-test
claude

출처: Claude Code 공식 문서: 작업할 폴더에서 claude 실행

다음에 다시 켤 때

터미널을 열고 cd ppt-test을 넣은 뒤 claude를 넣으면 같은 폴더에서 다시 켜집니다. 끌 때는 exit를 넣습니다.

05넣은 문장

클로드 코드에 이 문장을 넣었습니다

회사 회의에서 우리 팀 신제품 '보온 텀블러'를 소개하는 발표 PPT를 8장으로 만들어 줘. 새 프로그램은 설치하지 말고 이 컴퓨터의 파워포인트로 만들어서 이 폴더에 product.pptx로 저장해.

따옴표 안의 주제와 장 수는 내 발표에 맞게 바꿉니다.

작업이 끝나면 클로드를 켠 ppt-test 폴더에 product.pptx가 생깁니다. 파일 탐색기(맥은 Finder)에서 그 폴더를 열고 파일을 두 번 클릭하면 파워포인트로 열립니다.

  • 테스트 일자: 2026년 11월 16일
  • 테스트 환경: Windows 11, 파워포인트 16.0, 클로드 코드 2.1.281

  • 미확인 범위: 맥과 파워포인트가 없는 컴퓨터에서는 테스트하지 않았습니다.
