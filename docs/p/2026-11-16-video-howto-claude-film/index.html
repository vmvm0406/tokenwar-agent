03결과

20초 수묵화 영상이 나왔습니다

붓질로 산이 그려지고 기와지붕에 눈이 쌓입니다. 배경 음악과 효과음도 코드로 만들었습니다.

04주의할 점

PC용 클로드 코드가 있어야 합니다

휴대폰 앱에서는 안 됩니다. Node.js, ffmpeg, Python이 깔려 있어야 하고, 한 편에 40분쯤 걸리며 토큰도 꽤 씁니다.

직접 해 본 결과

수묵화 화풍으로 산골 마을에 첫눈이 내리는 20초 영상이 나왔습니다. 붓질 하나가 산등성이가 되고, 기와지붕이 하나씩 그려진 뒤 눈이 내려 지붕이 하얘집니다. 배경 음악과 효과음도 코드로 만들었고, 처음 설치부터 완성까지 40분쯤 걸렸습니다.

주의할 점

  • 휴대폰 앱이 아니라 PC용 클로드 코드에서만 됩니다. Node.js 20 이상, ffmpeg 7 이상, Python 3.11 이상이 필요합니다.
  • 처음 쓸 때 화풍 자료와 도구를 내려받느라 몇 분 더 걸립니다.
  • 시작할 때 클로드가 목소리·음악 자료가 있는지 한 번 묻습니다. 없다고 하면 알아서 만듭니다.
  • 화풍 설명서는 비상업 이용(CC BY-NC) 조건이 붙어 있습니다. 만든 영상은 내 것이지만, 설명서 자체를 팔거나 퍼뜨리면 안 됩니다.
