메타 AI의 개인 사진
학습을 막습니다

메타는 인스타그램과 페이스북의 공개 게시물을 메타 AI 학습에 씁니다. 지금 메타 AI를 움직이는 모델은 Muse예요. 개인 사진 학습을 원하지 않으면 메타 개인정보 보호 센터에서 거부 신청을 할 수 있어요. 아래 순서대로 해 보세요.

공식 신청 링크

메타 개인정보 보호 센터에 걸린 링크예요. 로그인한 상태에서 열어 보세요.

  • 인스타그램 계정으로 신청 · 인스타그램 고객 센터
  • 페이스북 계정으로 신청 · 페이스북 고객 센터
  • 메타 개인정보 보호 센터 안내 페이지 · '이의를 제기할 권리' 항목

준비물

  • 인스타그램 또는 페이스북 계정 (로그인한 상태)
01신청 페이지

메타 신청 페이지에 들어갑니다

https://www.facebook.com/privacy/genai/

아래쪽 '이의를 제기할 권리'를 누릅니다.

02링크 누르기

'Instagram'을 누릅니다

'이의를 제기할 권리'를 펼치면 링크가 보입니다. 로그인하면 신청 양식이 열립니다.

03제출

'제출'을 누릅니다

열린 신청 양식에서 '제출'을 누릅니다. 메타가 앞으로 공개 게시물을 학습에 쓰지 않겠다는 확인 이메일을 보냅니다.

결과 예시

신청이 접수되면 메타가 공개 게시물을 앞으로 AI 학습에 쓰지 않겠다는 확인 이메일을 보내요. 신청은 같은 계정 센터에 묶인 계정 모두에 적용돼요.
