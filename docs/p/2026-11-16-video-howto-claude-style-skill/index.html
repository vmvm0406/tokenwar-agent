클로드에게 그림 그리는
손을 달아 주는 방법입니다

Lemo-Opuscar는 화풍 99개를 모은 클로드 코드용 스킬입니다. 제작자 Lemomo(LemoLab)가 깃허브에 공개했고, 화풍마다 코드로만 만든 예시 영상이 있습니다. 아래는 받는 곳, 등록 순서, 화풍을 골라 쓰는 프롬프트 예시입니다. 스킬 파일은 저희가 나눠 드리지 않으니 제작자 저장소에서 받으세요.

01받는 곳

제작자 깃허브에서만 받습니다

공식 저장소는 github.com/lemomo-ai/lemo-opuscar입니다. 공식 갤러리 lemomo-ai.github.io/lemo-opuscar에서 화풍마다 예시 영상을 먼저 보고 고를 수 있습니다. 저희는 스킬 파일을 따로 나눠 드리지 않습니다.

02처음이라면

터미널부터 엽니다

터미널은 마우스 대신 글자로 컴퓨터에 일을 시키는 창입니다. 커서만 깜빡이는 빈 창이 뜨면 맞게 연 것입니다. 이 페이지의 명령은 복사 버튼으로 복사해 그 창에 붙여 넣고 Enter를 누르면 됩니다.

윈도우

시작 메뉴에서 PowerShell을 검색해 열거나, Win + X를 누르고 Windows PowerShell(또는 터미널)을 고릅니다. 줄 앞에 PS가 붙어 있으면 PowerShell입니다. 붙여 넣기는 Ctrl + V 또는 마우스 오른쪽 클릭.

출처: Claude Code 공식 문서: 처음 쓰는 사람을 위한 터미널 안내

맥

Cmd + Space로 Spotlight 검색을 열고 '터미널'(Terminal)을 입력한 뒤 Enter. 붙여 넣기는 Cmd + V.

출처: Claude Code 공식 문서: 터미널 안내

리눅스

대부분의 배포판에서 Ctrl + Alt + T를 누르거나, 앱 메뉴에서 '터미널'을 찾습니다. 붙여 넣기는 Ctrl + Shift + V.

출처: Claude Code 공식 문서: 터미널 안내

03처음이라면

클로드 코드를 설치합니다

공식 문서에 있는 설치 명령 그대로입니다. 받는 동안 진행 표시가 없으니 창을 닫지 말고 기다립니다. 끝나면 터미널을 새로 열고 확인 명령을 넣어 버전 숫자가 나오면 성공입니다. 처음 claude를 실행하면 브라우저가 열려 로그인합니다. 무료 요금제로는 쓸 수 없고 Pro 이상 요금제가 필요합니다.

윈도우 (PowerShell)

irm https://claude.ai/install.ps1 | iex

출처: Claude Code 공식 문서: 설치

윈도우 (CMD, 줄 앞에 PS가 없는 창)

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

출처: Claude Code 공식 문서: 설치

맥 · 리눅스

curl -fsSL https://claude.ai/install.sh | bash

출처: Claude Code 공식 문서: 설치

설치 확인 (공통)

2.1.281 (Claude Code)처럼 버전이 나오면 됩니다. claude를 찾을 수 없다고 나오면 터미널을 닫았다 다시 열어 봅니다.

claude --version

출처: Claude Code 공식 문서: 설치 확인

04처음이라면

Node.js·ffmpeg·Python을 깝니다

화풍 스킬이 영상을 만들 때 쓰는 도구입니다. 제작자 안내 기준 Node 20 이상, ffmpeg 7 이상, Python 3.11 이상이 필요합니다. 다 깔았으면 터미널을 새로 열고 맨 아래 확인 명령으로 버전을 봅니다.

윈도우

윈도우에 들어 있는 앱 설치 도구 winget으로 깝니다. 첫 줄은 Node.js, 둘째 줄은 ffmpeg(공식 사이트가 안내하는 gyan.dev 빌드), 셋째 줄은 Python 설치 관리자입니다. Python은 설치 관리자를 깐 뒤 처음 python을 실행할 때 최신판이 저절로 깔립니다.

winget install --id OpenJS.NodeJS.LTS -e
winget install --id Gyan.FFmpeg -e
winget install 9NQ7512CXL7T -e --accept-package-agreements --disable-interactivity

출처: Python 공식 문서: 윈도우에서 쓰기 · gyan.dev ffmpeg 빌드

맥

앱 설치 도구 Homebrew가 없으면 첫 줄로 먼저 깔고, 둘째 줄로 Node.js와 ffmpeg를 깝니다. Python은 python.org 다운로드 페이지의 macOS 설치 파일(.pkg)을 받아 엽니다.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install node ffmpeg

출처: Homebrew 공식 사이트 · Python 공식 다운로드

리눅스 (우분투·데비안)

Python은 배포판 것으로 충분합니다(우분투 24.04는 3.12). Node.js와 ffmpeg는 우분투 24.04 기본 저장소 판이 Node 18, ffmpeg 6.1로 낮습니다. Node.js는 nodejs.org 다운로드 페이지에서 Linux용을 받고, ffmpeg는 ffmpeg.org 다운로드 페이지가 안내하는 Linux 정적 빌드를 받습니다. 다른 배포판도 버전부터 확인합니다.

sudo apt install python3

출처: Node.js 공식 다운로드 · FFmpeg 공식 다운로드

버전 확인 (공통)

윈도우는 python, 맥·리눅스는 python3를 넣습니다. 숫자가 위 기준보다 낮으면 새로 깝니다.

node --version
ffmpeg -version
python --version
05클로드 코드에 등록

터미널에 두 줄을 넣습니다

claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab
06등록 확인

설치 목록에 바로 뜹니다

claude plugin list를 넣으면 lemo-opuscar@lemolab이 enabled로 보입니다. 저희는 첫 줄이 19초쯤, 둘째 줄은 바로 끝났습니다. 화풍 설명서와 도구는 처음 쓸 때 내 컴퓨터로 받아 옵니다.

07화풍 골라 쓰기

화풍 이름을 넣어 말합니다

Lemo-Opuscar 스킬로, Red Paper-cut(빨간 종이 오림) 화풍의 릴스 장면 전환용 짧은 영상을 만들어 줘. 질문하지 말고 스토리보드 확인 없이 바로 끝까지 만들어 줘.

저희가 이 릴스의 장면 전환을 만들 때 넣은 요청의 첫 부분입니다. 이어서 크기(1920x1080), 길이(1초짜리 전환 8개), 종이가 화면을 덮었다가 빠져나가는 움직임, 합성용 초록 배경을 적었습니다.

08클로드 앱(claude.ai)

클로드 앱은 zip으로 올립니다

공식 도움말 순서입니다(메뉴 이름은 영어 화면 기준). Settings → Capabilities에서 Code execution and file creation을 켭니다. 그다음 Customize → Skills에서 + → + Create skill → Upload a skill을 눌러 스킬 폴더를 묶은 zip을 올리고, 목록에서 켜면 됩니다.

직접 해 본 결과

11월 16일 이 컴퓨터의 클로드 코드(2.1.281)에 위 두 줄을 넣었습니다. 첫 줄은 19초쯤 걸려 'lemolab' 마켓플레이스가 추가됐고, 둘째 줄은 바로 'lemo-opuscar@lemolab' 설치가 끝났습니다. claude plugin list에 enabled로 떴고, claude plugin details로 보면 스킬 1개(lemo-opuscar)가 들어 있었습니다. 이어서 Red Paper-cut 화풍으로 릴스 장면 전환 8개(8초)를 만들었습니다. 스킬을 부르고 패키지 설치, 무늬 한 번 고치기, 8초 영상 뽑기까지 5분쯤 걸렸고, 이 릴스의 장면 전환이 그 결과입니다. 긴 영상 한 편(제작자 안내 30~60분)과 클로드 앱 업로드는 해 보지 않았습니다.

더 써 볼 문장

지우고 싶을 때

claude plugin uninstall lemo-opuscar@lemolab

제작자 안내 명령입니다. 처음 쓸 때 받아 온 ~/lemo-opuscar 폴더는 따로 지워야 합니다.
