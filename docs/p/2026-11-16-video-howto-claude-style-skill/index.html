클로드에 화풍 99개를
꽂는 순서입니다

Lemo-Opuscar는 화풍 99개를 모은 클로드 코드용 스킬입니다. 제작자 Lemomo(LemoLab)가 깃허브에 공개했고, 화풍마다 코드로만 만든 예시 영상이 있습니다. 아래는 받는 곳, 등록 순서, 화풍을 골라 쓰는 프롬프트 예시입니다. 스킬 파일은 저희가 나눠 드리지 않으니 제작자 저장소에서 받으세요.

01받는 곳

제작자 깃허브에서만 받습니다

공식 저장소는 github.com/lemomo-ai/lemo-opuscar입니다. 공식 갤러리 lemomo-ai.github.io/lemo-opuscar에서 화풍마다 예시 영상을 먼저 보고 고를 수 있습니다. 저희는 스킬 파일을 따로 나눠 드리지 않습니다.

02클로드 코드에 등록

터미널에 두 줄을 넣습니다

claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab

03등록 확인

설치 목록에 바로 뜹니다

claude plugin list를 넣으면 lemo-opuscar@lemolab이 enabled로 보입니다. 저희는 첫 줄이 19초쯤, 둘째 줄은 바로 끝났습니다. 화풍 설명서와 도구는 처음 쓸 때 내 컴퓨터로 받아 옵니다.

04화풍 골라 쓰기

화풍 이름을 넣어 말합니다

우키요에 화풍으로 우리 동네 빵집을 소개하는 30초 영상 만들어 줘

05클로드 앱(claude.ai)

클로드 앱은 zip으로 올립니다

공식 도움말 순서입니다(메뉴 이름은 영어 화면 기준). Settings → Capabilities에서 Code execution and file creation을 켭니다. 그다음 Customize → Skills에서 + → + Create skill → Upload a skill을 눌러 스킬 폴더를 묶은 zip을 올리고, 목록에서 켜면 됩니다.

직접 해 본 결과

11월 16일 이 컴퓨터의 클로드 코드(2.1.281)에 위 두 줄을 넣었습니다. 첫 줄은 19초쯤 걸려 'lemolab' 마켓플레이스가 추가됐고, 둘째 줄은 바로 'lemo-opuscar@lemolab' 설치가 끝났습니다. claude plugin list에 enabled로 떴고, claude plugin details로 보면 스킬 1개(lemo-opuscar)가 들어 있었습니다. 영상 한 편을 끝까지 만드는 것과 클로드 앱에 올리는 것은 직접 해 보지 않았습니다.

더 써 볼 문장

어떤 화풍을 고를지 모를 때

/lemo-opuscar:lemo-opuscar

제작자 안내에 따르면 이것만 넣으면 언어를 묻고, 라이브러리 화풍으로 만들지, 화풍을 내 것으로 고칠지, 저장해 둔 화풍을 쓸지 차례로 묻습니다. 저희는 돌려 보지 않았습니다.

지우고 싶을 때

claude plugin uninstall lemo-opuscar@lemolab

제작자 안내 명령입니다. 처음 쓸 때 받아 온 ~/lemo-opuscar 폴더는 따로 지워야 합니다.

주의할 점

  • 라이선스: 코드는 MIT, 예시 영상·그림은 CC BY 4.0, 화풍 설명서(STYLE.md 등)는 CC BY-NC 4.0입니다. 설명서로 내 영상을 만드는 것은 상업용까지 된다고 제작자가 따로 허락했지만, 설명서를 다시 나눠 주거나 파는 것은 따로 허락이 필요합니다. 자세한 것은 저장소의 LICENSE 파일을 보세요.
  • 클로드 앱 등록 순서는 Claude 공식 도움말(11월 16일 확인)을 옮긴 것입니다. 제작자는 클로드 코드 설치를 권장하고, 이 스킬은 내 컴퓨터의 Node·ffmpeg로 영상을 그립니다.
  • 클로드가 명령을 실행하고 파일을 만드니, 작업 중 묻는 허락을 확인하고 눌러 주세요. 빈 폴더에서 시작하세요.
  • PC가 필요합니다: Node 20 이상, ffmpeg 7 이상, Python 3.11 이상이 깔려 있어야 한다고 제작자가 안내합니다
  • 시간과 토큰: 영상 한 편에 30~60분이 걸리고 토큰을 꽤 쓴다고 제작자가 밝혔습니다
  • 저희가 확인한 범위: 클로드 코드 설치와 목록 확인까지 직접 했고, 영상 한 편 완성과 클로드 앱 업로드는 해 보지 않았습니다
