Lemo-Opuscar는 화풍 99개를 모은 클로드 코드용 스킬입니다. 제작자 Lemomo(LemoLab)가 깃허브에 공개했고, 화풍마다 코드로만 만든 예시 영상이 있습니다. 아래는 처음 사용하는 분을 위한 준비(터미널, 클로드 코드, 필요한 프로그램)부터 스킬 등록, 화풍 골라 영상 받기까지의 순서입니다.

스킬은 제작자 깃허브에 있습니다

스킬 파일은 별도로 배포하지 않으며, 따로 내려받을 필요도 없습니다. 아래 '터미널에 두 줄' 단계의 명령이 제작자 저장소에서 스킬을 받아 클로드 코드에 등록합니다. 화풍은 갤러리에서 예시 영상을 보고 고릅니다.

  • 공식 저장소: github.com/lemomo-ai/lemo-opuscar
  • 공식 갤러리: lemomo-ai.github.io/lemo-opuscar · 화풍마다 예시 영상
01사전 준비

터미널부터 엽니다

터미널은 마우스 대신 글자로 컴퓨터에 일을 시키는 창입니다. 커서만 깜빡이는 빈 창이 뜨면 맞게 연 것입니다. 이 페이지의 명령은 복사 버튼으로 복사해 그 창에 붙여 넣고 Enter를 누르면 됩니다.

윈도우

시작 메뉴에서 PowerShell을 검색해 열거나, Win + X를 누르고 Windows PowerShell(또는 터미널)을 고릅니다. 줄 앞에 PS가 붙어 있으면 PowerShell입니다. 붙여 넣기는 Ctrl + V 또는 마우스 오른쪽 클릭입니다.

출처: Claude Code 공식 문서: 처음 쓰는 사람을 위한 터미널 안내

맥

Cmd + Space로 Spotlight 검색을 열고 '터미널'(Terminal)을 입력한 뒤 Enter를 누릅니다. 붙여 넣기는 Cmd + V입니다.

출처: Claude Code 공식 문서: 터미널 안내

리눅스

대부분의 배포판에서 Ctrl + Alt + T를 누르거나, 앱 메뉴에서 '터미널'을 찾습니다. 붙여 넣기는 Ctrl + Shift + V입니다.

출처: Claude Code 공식 문서: 터미널 안내

02사전 준비

클로드 코드를 설치합니다

공식 문서에 있는 설치 명령 그대로입니다. 받는 동안 진행 표시가 없으니 창을 닫지 말고 기다립니다. 끝나면 터미널을 새로 열고 확인 명령을 넣어 버전 숫자가 나오면 성공입니다. 처음 claude를 실행하면 브라우저가 열려 로그인합니다. 무료 요금제로는 쓸 수 없고 Pro 이상 요금제가 필요합니다.

윈도우 (PowerShell)

irm https://claude.ai/install.ps1 | iex

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

출처: Claude Code 공식 문서: 설치

맥 · 리눅스

curl -fsSL https://claude.ai/install.sh | bash

claude --version

03사전 준비

Node.js·ffmpeg·Python을 설치합니다

화풍 스킬이 영상을 만들 때 쓰는 프로그램입니다. 제작자 안내 기준 Node 20 이상, ffmpeg 7 이상, Python 3.11 이상이 필요합니다. 클로드 코드를 먼저 설치했으므로, 설치는 클로드에게 맡기는 방법을 권장합니다.

권장 방법: 클로드에게 맡기기

앞 단계에서 설치한 클로드 코드에 설치를 맡깁니다. 터미널에 claude를 넣어 켜고, 켜진 창에 아래 문장을 붙여 넣고 Enter를 누릅니다. 클로드가 내 컴퓨터에 맞는 방법으로 설치하며, 명령을 실행하기 전마다 허락을 묻습니다. 내용을 확인한 뒤 승인합니다. 관리자 비밀번호가 필요한 명령은 클로드 창에서 바로 실행되지 않을 수 있습니다. 이 경우 클로드가 알려 주는 명령을 터미널 창을 하나 더 열어 직접 넣습니다. 다 끝나면 exit를 넣어 클로드를 끄고, 터미널을 닫았다 다시 연 뒤 맨 아래 확인 명령으로 버전을 봅니다.

Node.js 20 이상, ffmpeg 7 이상, Python 3.11 이상을 이 컴퓨터에 설치해 줘. 이미 깔려 있으면 버전만 확인해 주고, 기준보다 낮으면 새 버전으로 깔아 줘.

출처: Claude Code 공식 문서: 터미널 안내(켜기·끄기)

직접 설치하는 경우: 윈도우

윈도우에 들어 있는 앱 설치 도구 winget으로 설치합니다. 첫 줄은 Node.js, 둘째 줄은 ffmpeg(공식 사이트가 안내하는 gyan.dev 빌드), 셋째 줄은 Python 설치 관리자입니다. Python은 설치 관리자를 설치한 뒤 처음 python을 실행할 때 최신판이 자동으로 설치됩니다.

winget install --id OpenJS.NodeJS.LTS -e
winget install --id Gyan.FFmpeg -e
winget install 9NQ7512CXL7T -e --accept-package-agreements --disable-interactivity

출처: Python 공식 문서: 윈도우에서 쓰기 · gyan.dev ffmpeg 빌드

직접 설치하는 경우: 맥

앱 설치 도구 Homebrew가 없으면 첫 줄로 먼저 설치합니다. 넣으면 무엇을 할지 설명하고 멈추는데, Enter를 누르면 진행합니다. 맥 로그인 비밀번호를 물으면 입력합니다. 입력해도 화면에 아무것도 표시되지 않는 것이 정상이므로, 입력을 마치면 Enter를 누릅니다. 설치가 끝나면 맨 아래 'Next steps'에 PATH에 추가하는 명령(brew shellenv가 들어간 줄)이 나옵니다. 화면에 나온 그대로 복사해 넣어야 brew 명령이 인식됩니다. 공식 문서에 따르면 이 안내를 따르지 않으면 Homebrew가 작동하지 않습니다. 그다음 터미널을 새로 열고 둘째 줄로 Node.js와 ffmpeg를 설치합니다. Python은 python.org 다운로드 페이지의 macOS 설치 파일(.pkg)을 받아 엽니다.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install node ffmpeg

출처: Homebrew 공식 사이트 · Homebrew 공식 문서: 설치 · Homebrew 설치 스크립트 · Python 공식 다운로드

직접 설치하는 경우: 리눅스 (우분투·데비안)

Python은 배포판 것으로 충분합니다(우분투 24.04는 3.12). Node.js와 ffmpeg는 우분투 24.04 기본 저장소 판이 Node 18, ffmpeg 6.1로 기준보다 낮습니다. 그래서 리눅스는 위의 '클로드에게 맡기기' 방법을 권장합니다. 직접 하려면 Node.js는 nodejs.org 다운로드 페이지에서 Linux용을 받고, ffmpeg는 ffmpeg.org 다운로드 페이지가 안내하는 Linux 정적 빌드를 받습니다.

sudo apt install python3

출처: Node.js 공식 다운로드 · FFmpeg 공식 다운로드

버전 확인 (공통)

윈도우는 python, 맥·리눅스는 python3를 넣습니다. 숫자가 위 기준보다 낮으면 새로 설치합니다.

node --version
ffmpeg -version
python --version
04클로드 코드에 등록

터미널에 두 줄을 넣습니다

claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab

클로드를 켜기 전, 터미널에 바로 넣습니다. 두 줄을 한꺼번에 붙여 넣지 말고, 첫 줄을 넣고 Enter를 누른 뒤, 끝나면 둘째 줄을 넣고 Enter를 누릅니다. 이 명령이 제작자 저장소에서 스킬을 받아 클로드 코드에 등록합니다.

05등록 확인

설치 목록에 바로 뜹니다

claude plugin list를 넣으면 lemo-opuscar@lemolab이 enabled로 보입니다. 저희는 첫 줄이 19초쯤, 둘째 줄은 바로 끝났습니다. 화풍 설명서와 도구는 처음 쓸 때 내 컴퓨터로 받아 옵니다.

06클로드 켜기

빈 폴더를 만들고 그 안에서 클로드를 켭니다

클로드는 켠 폴더 안에 파일을 만듭니다. 영상 재료와 결과가 다른 파일과 섞이지 않게 빈 폴더를 하나 만들어 그 안에서 켭니다. 터미널을 새로 열고 아래 세 줄을 한 줄씩 넣고 Enter를 누릅니다. 첫 줄은 lemo-film이라는 빈 폴더를 만들고, 둘째 줄(cd)은 그 폴더로 들어가고, 셋째 줄이 클로드를 켭니다. 켜진 창이 다음 단계의 요청을 붙여 넣을 곳입니다. 파일을 만들거나 바꾸기 전에 허락을 물으면 내용을 확인한 뒤 Enter로 승인합니다.

윈도우 (PowerShell)

터미널은 C:\Users\내 이름 폴더에서 시작하므로, 새 폴더는 C:\Users\내 이름\lemo-film에 생깁니다.

mkdir lemo-film
cd lemo-film
claude

출처: Claude Code 공식 문서: 작업할 폴더에서 claude 실행

맥 · 리눅스

터미널은 내 홈 폴더(맥은 /Users/내 이름, 리눅스는 /home/내 이름)에서 시작하므로, 새 폴더는 그 안에 lemo-film으로 생깁니다.

mkdir lemo-film
cd lemo-film
claude

출처: Claude Code 공식 문서: 작업할 폴더에서 claude 실행

다음에 다시 켤 때

터미널을 열고 cd lemo-film을 넣은 뒤 claude를 넣으면 같은 폴더에서 다시 켜집니다. 끌 때는 exit를 넣습니다.

07화풍 골라 쓰기

화풍 이름을 넣어 말합니다

Lemo-Opuscar 스킬로, Red Paper-cut(빨간 종이 오림) 화풍의 릴스 장면 전환용 짧은 영상을 만들어 줘. 질문하지 말고 스토리보드 확인 없이 바로 끝까지 만들어 줘.

저희가 이 릴스의 장면 전환을 만들 때 넣은 요청의 첫 부분입니다. 이어서 크기(1920x1080), 길이(1초짜리 전환 8개), 종이가 화면을 덮었다가 빠져나가는 움직임, 합성용 초록 배경을 적었습니다.

앞 단계에서 켠 클로드 창에 붙여 넣습니다. 화풍 이름은 공식 갤러리에 적힌 영어 이름(예: Red Paper-cut)을 그대로 복사해 프롬프트의 화풍 이름 자리에 넣으면 됩니다.

08결과 영상

완성 영상은 그 폴더 안에 생깁니다

스킬 지침에 따르면 클로드를 켠 폴더(앞의 lemo-film) 안에 작품 이름으로 폴더가 하나 생기고, 그 안에 완성 영상 <작품 이름>.mp4와 대표 그림 poster.jpg가 놓입니다. 다 만들면 클로드가 위치를 알려 줍니다. 테스트에서 만든 장면 전환도 작업 폴더 안에 mp4로 생성되었습니다. 윈도우는 파일 탐색기, 맥은 Finder, 리눅스는 파일 관리자에서 lemo-film 폴더를 찾아 mp4를 두 번 누르면 열립니다. 제작자 안내로 한 편에 30~60분이 걸리니, 만드는 동안 터미널 창을 닫지 마십시오.

출처: Lemo-Opuscar 공식 저장소 (스킬 지침 plugin/skills/lemo-opuscar/SKILL.md, DIRECTOR.md 11장)

09클로드 앱(claude.ai)

클로드 앱은 zip으로 올립니다

공식 도움말 순서입니다(메뉴 이름은 영어 화면 기준). Settings → Capabilities에서 Code execution and file creation을 켭니다. 그다음 Customize → Skills에서 + → + Create skill → Upload a skill을 눌러 스킬 폴더를 묶은 zip을 올리고, 목록에서 켜면 됩니다.

zip 얻는 법: 공식 저장소 첫 화면에서 파일 목록 위 Code 버튼 → Download ZIP으로 저장소 전체를 받습니다(깃허브 공식 안내). 압축을 풀면 스킬 폴더는 plugin/skills/lemo-opuscar입니다. Claude 도움말은 스킬 폴더를 zip으로 묶어 올리라고 안내하므로, 이 폴더만 다시 zip으로 묶어 올립니다. 클로드 앱 업로드는 직접 테스트하지 않았습니다. 업로드가 되지 않으면 클로드 코드 방법을 이용하십시오.

출처: 깃허브 공식 문서: 소스 코드 압축 파일 받기 · Claude 도움말: Use skills in Claude

테스트 환경 및 결과

  • 테스트 일자: 2026년 11월 16일
  • 테스트 환경: Windows 11, 클로드 코드 2.1.281
  • 등록: '터미널에 두 줄' 단계의 명령 중 첫 줄(마켓플레이스 추가)은 약 19초, 둘째 줄(lemo-opuscar@lemolab 설치)은 바로 완료되었습니다.
  • 등록 확인: claude plugin list에서 enabled로 표시되었고, claude plugin details에서 스킬 1개(lemo-opuscar)를 확인했습니다.

  • 미확인 범위: 긴 영상 한 편(제작자 안내 30~60분)과 클로드 앱 업로드는 테스트하지 않았습니다.
