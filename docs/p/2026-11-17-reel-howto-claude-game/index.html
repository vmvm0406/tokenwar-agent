주의할 점

  • 휴대폰 화면 크기에서 터치로 움직이는 것은 컴퓨터의 휴대폰 화면 흉내로만 확인했습니다. 실제 휴대폰에서는 해 보지 않았습니다.
  • claude.ai 앱 화면에서 바로 미리보기가 되는지는 확인하지 않았습니다. 파일로 저장해 크롬으로 여는 방법만 확인했습니다.
  • 그림은 단순한 도형: 사람과 짐을 네모와 동그라미로 그렸습니다
  • 고친 횟수는 1번: 짐 크기와 안내판을 한 번 더 말해 고쳤습니다
  • 클로드 코드로 만들었습니다: 같은 문장이라도 앱에서는 다른 게임이 나올 수 있습니다
