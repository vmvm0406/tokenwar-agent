prompt.md 전체 번역

최신 콜 오브 듀티 게임 수준의 1인칭 슈팅 게임을 만들어 줘. 텍스처부터 물리까지 생각할 수 있는 모든 것을 AAA급 품질로, 흠잡을 데 없이 완벽하고 눈부시게 아름답게 만들어야 해.

서브 에이전트들을 펼쳐서 항목을 하나씩 따로 맡겨 게임이 완벽해지게 해. 항목마다 /loop를 돌리고, 별도의 서브 에이전트가 화면을 직접 보고 AAA급으로 보이는지 확인하게 해. 그 서브 에이전트는 아주 깐깐한 비평가여야 하고, AAA급으로 보이지 않으면 계속 고치게 해.

모든 서브 에이전트가 실제 콜 오브 듀티와 비교해 품질에 완전히 감탄할 때까지 멈추지 마. 둘을 나란히 놓고 어느 쪽인지 모르는 상태(블라인드)로 비교해서 어느 쪽이 더 나은지 말하게 해. Three.js로 만들어. 완벽해질 때까지 /loop. 서브 에이전트를 펼치고 ultracode.

원문은 영어 3문단입니다. /loop와 ultracode는 클로드 코드에서 쓰는 명령이라 영어 그대로 두었습니다. 클로드 앱 대화창이 아니라 클로드 코드에 넣는 프롬프트입니다.

공개 코드 실행 방법 (Node.js 설치 후 터미널에서)

git clone https://github.com/mshumer/Claude-of-Duty
cd Claude-of-Duty
npm install
npm run dev

크롬에서 http://127.0.0.1:5173 을 열고 화면을 누르면 시작합니다. WASD 이동, 마우스 조준, 왼쪽 클릭 사격, 오른쪽 클릭 조준경, R 재장전입니다. 저희 컴퓨터에서는 처음 불러오는 데 1분 넘게 걸렸습니다.

주의할 점

  • README의 '솔직한 평가'에 따르면 목표였던 최신 콜 오브 듀티 수준에는 못 미칩니다. AI 비평가 11명이 매긴 점수는 10점 만점에 5.05점이 최고였고, 블라인드 비교에서는 매번 진짜 콜 오브 듀티 화면이 골라졌습니다.
  • 게임이 무겁습니다. README 기준 애플 노트북에서 초당 28~30프레임입니다. 그래픽 카드가 약한 컴퓨터에서는 느릴 수 있습니다.
  • 같은 프롬프트를 넣어도 같은 게임이 나오지 않습니다. 서브 에이전트를 여러 개 띄워 오래 돌리므로 클로드 코드 사용량이 많이 듭니다.
  • 콜 오브 듀티 수준은 아닙니다: 만든 사람도 블라인드 비교에서 진짜 게임이 이겼다고 적었습니다
  • 클로드 코드용 프롬프트입니다: 서브 에이전트와 /loop를 쓰고 오래 돌아갑니다
  • 저희는 공개 코드를 실행했습니다: 같은 프롬프트로 처음부터 다시 만들지는 않았습니다
