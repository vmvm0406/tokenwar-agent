TOKEN WAR

프롬프트 3문단으로
FPS 게임이 나왔습니다

Matt Shumer가 클로드 Opus 5와 클로드 코드로 만든 브라우저 FPS 게임 Claude-of-Duty의 프롬프트와 사용법입니다. 코드와 프롬프트는 오픈소스(MIT 라이선스, Copyright (c) 2026 mshumer)로 공개되어 있습니다. 아래 번역은 원문 prompt.md를 토큰전쟁이 한국어로 옮긴 것입니다. /loop와 ultracode는 클로드 코드에서 쓰는 명령이라 영어 그대로 두었습니다. 클로드 앱 대화창이 아니라 클로드 코드에 넣는 프롬프트입니다.

01사전 준비

터미널부터 엽니다

터미널은 마우스 대신 글자로 컴퓨터에 일을 시키는 창입니다. 커서만 깜빡이는 빈 창이 뜨면 맞게 연 것입니다. 이 페이지의 명령은 복사 버튼으로 복사해 그 창에 붙여 넣고 Enter를 누르면 됩니다.

윈도우

시작 메뉴에서 PowerShell을 검색해 열거나, Win + X를 누르고 Windows PowerShell(또는 터미널)을 고릅니다. 줄 앞에 PS가 붙어 있으면 PowerShell입니다. 붙여 넣기는 Ctrl + V 또는 마우스 오른쪽 클릭입니다.

출처: Claude Code 공식 문서: 처음 쓰는 사람을 위한 터미널 안내

맥

Cmd + Space로 Spotlight 검색을 열고 '터미널'(Terminal)을 입력한 뒤 Enter를 누릅니다. 붙여 넣기는 Cmd + V입니다.

출처: Claude Code 공식 문서: 터미널 안내

리눅스

대부분의 배포판에서 Ctrl + Alt + T를 누르거나, 앱 메뉴에서 '터미널'을 찾습니다. 붙여 넣기는 Ctrl + Shift + V입니다.

출처: Claude Code 공식 문서: 터미널 안내

02사전 준비

클로드 코드를 설치합니다

공식 문서에 있는 설치 명령 그대로입니다. 받는 동안 진행 표시가 없으니 창을 닫지 말고 기다립니다. 끝나면 터미널을 새로 열고 확인 명령을 넣어 버전 숫자가 나오면 성공입니다. 처음 claude를 실행하면 브라우저가 열려 로그인합니다. 무료 요금제로는 쓸 수 없고 Pro 이상 요금제가 필요합니다.

윈도우 (PowerShell)

irm https://claude.ai/install.ps1 | iex

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

출처: Claude Code 공식 문서: 설치

맥 · 리눅스

curl -fsSL https://claude.ai/install.sh | bash

claude --version

03클로드 켜기

빈 폴더를 만들고 그 안에서 클로드를 켭니다

클로드는 켠 폴더 안에 파일을 만듭니다. 게임 파일이 다른 파일과 섞이지 않도록 빈 폴더를 하나 만들어 그 안에서 켭니다. 터미널을 새로 열고 아래 세 줄을 한 줄씩 넣고 Enter를 누릅니다. 첫 줄은 fps-game이라는 빈 폴더를 만들고, 둘째 줄(cd)은 그 폴더로 들어가고, 셋째 줄이 클로드를 켭니다. 켜진 창이 다음 단계의 프롬프트를 붙여 넣을 곳입니다. 파일을 만들거나 바꾸기 전에 허락을 물으면 내용을 확인한 뒤 Enter로 승인합니다.

윈도우 (PowerShell)

터미널은 C:\Users\내 이름 폴더에서 시작하므로, 새 폴더는 C:\Users\내 이름\fps-game에 생깁니다.

mkdir fps-game
cd fps-game
claude

출처: Claude Code 공식 문서: 작업할 폴더에서 claude 실행

맥 · 리눅스

터미널은 내 홈 폴더(맥은 /Users/내 이름, 리눅스는 /home/내 이름)에서 시작하므로, 새 폴더는 그 안에 fps-game으로 생깁니다.

mkdir fps-game
cd fps-game
claude

출처: Claude Code 공식 문서: 작업할 폴더에서 claude 실행

다음에 다시 켤 때

터미널을 열고 cd fps-game을 넣은 뒤 claude를 넣으면 같은 폴더에서 다시 켜집니다. 끌 때는 exit를 넣습니다.

04prompt.md 전체 번역

클로드 코드에 이 3문단을 넣었습니다

최신 콜 오브 듀티 게임 수준의 1인칭 슈팅 게임을 만들어 줘. 텍스처부터 물리까지 생각할 수 있는 모든 것을 AAA급 품질로, 흠잡을 데 없이 완벽하고 눈부시게 아름답게 만들어야 해.
서브 에이전트들을 펼쳐서 항목을 하나씩 따로 맡겨 게임이 완벽해지게 해. 항목마다 /loop를 돌리고, 별도의 서브 에이전트가 화면을 직접 보고 AAA급으로 보이는지 확인하게 해. 그 서브 에이전트는 아주 깐깐한 비평가여야 하고, AAA급으로 보이지 않으면 계속 고치게 해.
모든 서브 에이전트가 실제 콜 오브 듀티와 비교해 품질에 완전히 감탄할 때까지 멈추지 마. 둘을 나란히 놓고 어느 쪽인지 모르는 상태(블라인드)로 비교해서 어느 쪽이 더 나은지 말하게 해. Three.js로 만들어. 완벽해질 때까지 /loop. 서브 에이전트를 펼치고 ultracode.

앞 단계에서 fps-game 폴더 안에 켠 클로드 창에 세 문단을 한 번에 붙여 넣고 Enter를 누릅니다. 원문(영어)을 넣으려면 저장소의 prompt.md를 복사하십시오. 작업은 여러 시간 이어지며, 중간에 멈추려면 Esc를 누릅니다.

출처: 원문 prompt.md · Claude Code 공식 문서: 터미널 안내(Esc로 멈추기)

05결과 확인

만든 게임을 브라우저에서 엽니다

게임 파일은 클로드를 켠 fps-game 폴더 안에 생깁니다. 여는 방법은 클로드가 고른 구성에 따라 다르므로, 작업이 끝나면 같은 창에 아래 문장을 넣어 실행 방법을 확인하십시오. 원본 Claude-of-Duty는 Three.js로 만든 웹 게임이라 터미널에서 개발 서버를 켜고 브라우저 주소창에 주소를 넣어 엽니다(다음 단계 참고). 서버를 켠 터미널 창은 게임을 하는 동안 닫지 마십시오.

클로드 창에 넣을 문장

만든 게임을 브라우저에서 여는 방법을 알려 주고, 필요하면 실행까지 해 줘.
06내 컴퓨터에서 실행하기

공개된 코드를 받아 직접 돌려 봤습니다

Node.js를 깔고 명령 두 줄이면 크롬에서 열립니다.

새로 만들지 않고 제작자가 공개한 원본 게임만 실행해 볼 수도 있습니다. Node.js를 설치한 뒤 아래 명령을 한 줄씩 넣습니다. 끝나면 크롬 주소창에 http://127.0.0.1:5173 을 넣고 화면을 클릭하면 시작합니다. 저희 컴퓨터에서는 처음 불러오는 데 1분 넘게 걸렸습니다. 조작은 WASD 이동, 마우스 조준, 왼쪽 클릭 사격, 오른쪽 클릭 조준경, R 재장전, Esc 마우스 풀기입니다.

권장 방법: 클로드에게 맡기기

클로드 창에 아래 문장을 붙여 넣고 Enter를 누릅니다. 명령을 실행하기 전마다 허락을 요청하므로 내용을 확인한 뒤 승인합니다. 끝나면 exit로 클로드를 끄고 터미널을 새로 엽니다.

Node.js LTS 버전을 이 컴퓨터에 설치해 줘. 이미 깔려 있으면 버전만 확인해 줘.

직접 설치하는 경우: 윈도우

winget install --id OpenJS.NodeJS.LTS -e

출처: Node.js 공식 다운로드

직접 설치하는 경우: 맥

Homebrew가 설치되어 있다면 아래 명령을 넣습니다. 없다면 nodejs.org에서 macOS 설치 파일(.pkg)을 받습니다.

brew install node

출처: Homebrew: node

직접 설치하는 경우: 리눅스

우분투 24.04 기본 저장소의 Node.js는 18로 오래된 판입니다. nodejs.org 다운로드 페이지에서 Linux용을 받거나 클로드에게 맡기는 방법을 권장합니다.

테스트 환경 및 결과

  • 테스트 일자: 2026년 11월 16일
  • 테스트 환경: Windows 11, Node.js, 크롬
  • 실행: 공개 코드를 받아 npm install, npm run dev로 실행했습니다. 저장소에 포함된 녹화 도구(tools/demo.mjs, 봇 플레이)로 화면을 녹화했습니다.
  • 확인 내용: 그림·소리 파일 없이 시작할 때 코드로 벽 무늬와 총, 적 플레이어, 소리를 만들어 냅니다.
  • 미확인 범위: 같은 프롬프트로 게임을 처음부터 다시 만들어 보지는 않았습니다.

유의 사항

  • README의 '솔직한 평가'에 따르면 목표했던 상용 게임 수준에는 미치지 못합니다. AI 비평가 11명이 매긴 점수는 10점 만점에 5.05점이 최고였습니다.
  • 이 게임은 클로드 코드가 일을 나눠 맡는 보조 AI(서브 에이전트) 여러 개를 띄우고, 같은 작업을 반복하는 /loop 명령으로 여러 시간 스스로 작업해 만들었습니다. 그만큼 사용량이 매우 큽니다. 시작 전에 요금제의 사용 한도를 확인하십시오.
  • 같은 프롬프트를 넣어도 같은 게임이 나오지 않습니다. 결과는 실행할 때마다 달라집니다.
  • 게임이 무겁습니다. README 기준 애플 노트북에서 초당 28~30프레임이며, 그래픽 카드가 약한 컴퓨터에서는 느릴 수 있습니다.
  • 완성도에는 한계가 있습니다: 제작자도 상용 게임 수준에는 못 미친다고 밝혔습니다
  • 클로드 코드에서 쓰는 프롬프트입니다: 클로드 코드가 여러 시간 스스로 작업하는 방식입니다
  • 저희는 공개된 게임을 실행해 봤습니다: 저희가 같은 프롬프트로 새로 만든 결과는 아닙니다
