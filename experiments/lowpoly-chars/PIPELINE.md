# 3D 캐릭터 콩트 릴스 제작 순서 (운영자 결정 2026-11-18)

운영자가 정한 5단계. 이 순서대로 만든다.

```
① 캐릭터 원본 제작      머리·얼굴·몸·의상·관절
② 애니메이션 라이브러리  걷기·앉기·놀라기·춤추기·넘어지기
③ Three.js 장면 구성    사무실·집·카페·거리 등 배경
④ AI로 대본·장면 생성   대본에 따라 캐릭터 행동과 카메라 연출 지정
⑤ 영상 렌더링·MP4 출력
```

## ① 캐릭터 원본 — Blender 스크립트 (`build.py`) → glb
- **AI 캐릭터 3개(클로드·제미나이·챗GPT):** 로고 모양 몸(알아볼 수 있게 변형 OK), 팔다리 없음, 통통한 로우폴리. 3차 시안 완료.
  - 남은 일: 표정 부품을 이름 붙여 glb에 넣기 — 눈(기본·감음 ^^·놀람·찡그림·졸림), 입(웃음·아·이·우·시무룩·당황), 볼터치, 땀방울. three.js가 켜고 끔.
  - 몸 중심축을 바닥 가운데로 (통통 튀기·찌그러지기용).
- **사람 캐릭터 (운영자 2026-11-18 "일단 두 개"):** ① 젠슨 황(검정 가죽 재킷·회색 머리, 같은 로우폴리 화풍. 실제 인물이라 패러디로 분명히 하고, 실제로 하지 않은 말을 진짜 발언처럼 보이게 하지 않음) ② 일반 남성(평범한 직장인). 여성 '나'는 보류.
- **(보류) 주인공 '나':** 20대 한국 여성 직장인, 같은 로우폴리 화풍. 큰 머리(2.5등신), 단발, 후드티 + 사원증. Blender 스크립트로 모델 + 뼈대(머리·목·몸통·팔·다리 관절) + 얼굴은 AI 캐릭터와 같은 부품 방식.

## ② 애니메이션 라이브러리 — 이름으로 부르는 동작
- AI 캐릭터(팔다리 없음): 코드 동작(three.js) — 통통 걷기(튀며 이동), 앉기(찌그러져 내려앉기), 놀라기(펄쩍 + 늘어남 + 눈 커짐), 춤추기(좌우 흔들·한 바퀴), 넘어지기(기울어 쓰러짐 → 튕김), 끄덕·도리도리·부들부들·말하기 출렁.
- '나': Blender에서 뼈대 키프레임으로 만들어 glb 애니메이션 클립으로 (걷기·앉기·놀라기·춤추기·넘어지기·타자 치기·이마 짚기·한숨), three.js AnimationMixer로 섞음.
- 표정은 동작과 따로: `emotion: happy|surprised|sad|angry|embarrassed|sleepy`.

## ③ Three.js 장면 — 배경 프리셋
- 사무실(책상·모니터·키보드·꼬마전구 빛망울) 먼저, 그다음 집·카페·거리. 소품도 같은 로우폴리 화풍(Blender 스크립트 또는 CC0 소품).
- 조명·얕은 심도(빛망울)는 프리셋마다 고정.

## 목소리 정하기 (운영자 2026-11-18)
캐릭터마다 목소리를 한 번 정해 고정한다 (ElevenLabs). 후보를 2~3개씩 같은 대사로 들려주고 운영자가 고른다. 정한 목소리 ID·설정은 `voices.json`에 (키는 사용자 환경변수, 저장소에 값 없음).
- 나 / 클로드 / 챗GPT / 제미나이: 미정

## ④ 시나리오 회의 → 대본 확정 → 그다음에 제작 (운영자 2026-11-18, 항상)
영상을 만들기 전에 **반드시** 운영자와 시나리오 회의를 한다: 소식·상황·웃음 포인트·결말(팁)을 함께 정하고, 대본이 완성돼 운영자가 OK해야 ⑤ 렌더링에 들어간다. 대본 없이 바로 영상부터 만들지 않는다.

확정된 대본은 아래 JSON으로 쓴다 (직장 콩트: 위기 한 줄 → AI 반응 → 팁 하나 → '자료' DM).
```json
{"scene": "office", "cast": ["me", "claude", "chatgpt"],
 "lines": [
   {"who": "me", "text": "내일까지 보고서 50장이래…", "emotion": "sad", "action": "sit", "cam": "close:me"},
   {"who": "chatgpt", "text": "5분이면 돼!", "emotion": "happy", "action": "hop", "cam": "two:me,chatgpt"}
 ]}
```
- 목소리: ElevenLabs(캐릭터마다 목소리), 글자 시각으로 입 모양·대사 길이·컷 시각 자동.
- 카메라 문법: `wide`, `close:<누구>`, `two:<A>,<B>`, `push:<누구>`, `over:<A>,<B>`.

## ⑤ 렌더링 — 헤드리스 Chromium(GPU) → 프레임 → ffmpeg
- `experiments/threejs-test/render.py` 방식 그대로 (1080x1920 30fps, -14 LUFS, 30초 ≈ 1분).
- 위 라벨 띠·자막은 2D 캔버스 (검정 + 형광 초록, 안전 영역 285~1250px).
