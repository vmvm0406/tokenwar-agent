# 대본 초안 2차: 클로드한테 점심 하나 부탁했는데 (2026-11-18, 운영자 "점심은 클로드한테, 클로드랑만 대화해도 돼", 확정 전 제작 금지)

- 소재: 클로드가 크롬에서 탭을 오가며 버튼을 누르고 정보를 입력하는 기능 (ZDNet 2026-11-18). 제미나이 태스크는 이번 편에서 뺌(다음 편 후보).
- 참고 형식: AI에게 능력을 달아 줌 (255만) + 질문을 너무 많이 하는 비서 (154만). 시리즈: 눈(젠슨 편) → 그림 실력(리트냥이 편) → 손(이번).
- 출연: 남자 + 클로드만.

- 3번 클로드: "점심엔 김밥이 좋겠어요. 참치김밥? 김치김밥?" + "치즈김밥?"은 사나 실제 목소리 클립(아는 형님 76회, JTBC 공식 igwGdxz20gc) 1초 남짓 — 클로드 목소리가 갑자기 바뀌는 개그. AI 목소리 복제 아님, 원본 소리 짧게 + 출처 표기.
- 4번 남자: '치즈김밥'에 살짝 고개 들었다가 다시 엎드리며 "참치."
