# 마인크래프트 블록 파고들기 9편: 피스톤 (대본 초안 2026-11-23, 운영자 확정 전)

형식은 블록 시리즈 그대로: Deok, v3 한 번에 녹음 + 감정·쉬는 태그, 1.2배 안팎, 긴 쉼 줄이기, 끝 속삭임 저장본, 효과음 게임 소리. 목표 35~40초. 연도 띠: 2011 · 현재. 표지 "피스톤".

출처: minecraft.wiki Piston (History·Trivia)
- 2011-03-27 마인크래프트 포럼에 Hippoplatimus가 올린 피스톤 모드 → 코드를 젭(Jeb)에게 넘김 → 젭이 게임에 넣음. Hippoplatimus는 게임 크레딧 'Additional Programming'에 있음.
- Java 베타 1.7(2011-06)에 추가. 이 판에는 레드스톤 횃불을 밀려고 하는 등의 경우 게임이 꺼지고 그 월드에 못 들어가는 버그 → 1.7_01에서 고침(월드도 다시 열림).
- 한 번에 최대 12블록. 모장: "현재 제한은 의도한 설계" → 안 바꿈.
- 못 미는 블록: 흑요석, 베드락, 보강된 심층암(8편 위키 확인) 등.
- (뺀 것) 준연결성(QC): Java에서 피스톤 위 칸에 신호가 와도 움직임, 모장은 '의도한 기능' — 설명이 길어 이번엔 뺌.
현실: 자동차 엔진 피스톤 — 크랭크축 1회전에 피스톤 1번 오르내림 → 3,000rpm이면 1초에 50번.
