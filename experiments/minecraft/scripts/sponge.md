# 마인크래프트 블록 파고들기 1편: 스펀지 (대본 초안 1, 확정 전)

형식(운영자 2026-11-22): 순수 마인크래프트, 블록 하나를 깊게. 언제 나왔나 → 어떻게 되나 → 궁금할 만한 것(현실 이야기는 필요할 때만). 캐릭터 없음. 픽셀 화면 + 실제 블록 이미지 + 내레이션 하나. 약 45초, 장면 3~4초.

출처: minecraft.wiki Sponge 문서(History, Usage). 블록 이미지: minecraft.wiki 렌더(JE1 2009 / JE2 2014 / JE3 2018 / 젖은 스펀지).

## 점검
- 첫 대사 훅: 넓은 대상(마크 해 본 사람 누구나) · 감정(어? 의외) · 궁금증(왜 급하게?) — 3개 다.
- 픽세와 다르게: 과거형 다큐 말투("~했죠") 대신 말하듯 설명, "만약 ~라면", 남극 귀환, '좋아요 많은 만약에 댓글' 문구 안 씀.
- 끝맺음 틀(운영자 2026-11-22): "다음은 ○○ 블록에 대해 설명해 드리겠습니다" + 속삭임 "팔로우하고 딱 기다려~" (일레븐랩스 v3 [whispers] 태그). 매 편 같은 틀.
- 사실 확인 끝(2026-11-22, 영어 위키백과 Sponge·Henry Van Peters Wilson): 해면 뼈대를 청소 도구로 써서 같은 이름, 신경·소화·순환계 없음, 1907년 윌슨이 체로 걸러 흩은 세포가 다시 모여 해면이 됨을 보임. 3번 노치 말은 요약만.
- 마인크래프트 로고·게임 화면 녹화 없음. 블록 렌더 이미지 + 우리가 그린 픽셀 그림.
- 표지 제목: 스펀지 (운영자 2026-11-22, 블록 이름만 간단히).

## 정할 것

- 화면 글자는 "~이다" 같은 문장 끝 없이 명사로 (임시방편, 118톤, 뇌 X).

## 영상 구성 (제안, 확정 전)
- 화면 1080x1920. 배경은 어두운 단색 + 아주 옅은 픽셀 격자. 읽을 것은 세로 285~1250px 안.
- 주인공 블록: minecraft.wiki 블록 이미지를 흐림 없이(nearest) 크게, 화면 가운데. 천천히 돌거나 살짝 들썩임. 장면마다 크기·위치가 바뀜.
- 연도 띠(우리만의 표시): 화면 위쪽에 2009 ━ 2010 ━ 2014 ━ 2018 눈금. 이야기 시점에 맞춰 칸이 채워지며 지금 몇 년도인지 보여 줌.
- 숫자 장면: 0→118 올라가는 픽셀 숫자, 물 블록이 한 칸씩 빨려 들어가는 움직임.
- 픽셀 그림(물, 테이프, 화로, 네더, 바다 신전, 엘더 가디언 실루엣, 진짜 해면, 체)은 우리가 코드로 직접 그림. 게임 화면 녹화·로고·게임 소리·음악은 안 씀.
- 장면 전환 3~4초마다: 픽셀이 부서지며 넘어가기 / 블록이 툭 떨어지며 넘어가기.
- 글씨: 한국어 픽셀 폰트(갈무리, OFL 무료). 자막은 아래쪽 흰 글씨 + 검은 테두리, 문장마다 줄바꿈.
- 소리: 일레븐랩스 내레이션 하나 + 우리가 만든 짧은 효과음(뿅·치익·쿵). 끝 속삭임은 v3 [whispers].
- 제작: HTML 캔버스 장면 → Playwright로 프레임 → ffmpeg mp4 (새 스크립트 experiments/minecraft/). 내레이션 길이가 장면 길이를 정함.
