# 회사 로고 (연표 릴스 줄 표시용, 내레이션 릴스 로고 쾅)

`agent/timeline_reel.py`가 회사 줄 이름 앞과 지금 모델 줄에 작게(30~40px) 넣는다. 회사 이름을 알리는 지명적 사용(nominative use)만: 크게 꾸미거나 모양·비율을 바꾸지 않고, 회사 색 한 가지로 칠한다.

| 파일 | 회사 | 출처 |
|---|---|---|
| openai.svg | OpenAI | Simple Icons 15.0.0 (CC0 1.0, https://simpleicons.org) |
| google.svg | Google | Simple Icons 15.0.0 |
| anthropic.svg | Anthropic | Simple Icons 15.0.0 |
| meta.svg | Meta | Simple Icons 15.0.0 |
| googlegemini.svg | Google Gemini | Simple Icons 15.0.0 (CC0) |
| claude.svg | Claude (Anthropic) | Simple Icons 15.0.0 |
| alibabacloud.svg | Alibaba Cloud (Qwen 표시용) | Simple Icons 15.0.0 |
| gmail.svg | Gmail | Simple Icons 15.0.0 |
| googlemaps.svg | Google Maps | Simple Icons 15.0.0 |
| visa.svg | Visa | Simple Icons 15.0.0 |
| netflix.svg | Netflix | Simple Icons 15.0.0 |

xAI(Grok)·DeepSeek·Qwen 로고는 Simple Icons에 없어 로고 없이 회사 색 글자(워드마크)로 쓴다. SVG 그림 파일의 저작권은 CC0이지만 상표는 각 회사 것이다.
