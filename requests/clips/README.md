# 릴스 영상 요청

아침 작업이 여기에 요청을 넣으면, 회원님 컴퓨터가 켜져 있을 때 도는 '영상 받기' 작업(`CLIPS.md`)이
영상을 받아 15초 이하 구간을 고르고 릴스 게시물을 만든다. 처리한 요청은 `done/`으로 옮긴다.

```json
{
  "id": "2026-11-16-huang-jobs",
  "url": "https://www.youtube.com/watch?v=...",
  "kind": "기업가 인터뷰",
  "speaker": "젠슨 황 (엔비디아 CEO)",
  "credit": "채널 이름",
  "why": "모든 화이트칼라 직업이 바뀐다고 단정. 72시간 안에 나옴, 국내 미소개",
  "hint": "38:10 무렵, 'every white-collar job' 부분",
  "score": 9,
  "related_news": "https://... (같이 다룰 기사, 선택)",
  "requested_at": "2026-11-16T08:00:00+09:00"
}
```

- `hint`에 발언 문장이나 대략적인 시각을 적으면 받아쓰기에서 빨리 찾는다. 모르면 비워도 된다.
- `score`는 스타일 가이드 6-1장 점수표. 높은 것부터 처리하고 하루에 릴스는 1개만 만든다.
